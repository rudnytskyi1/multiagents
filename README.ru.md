# multiagents — краткое руководство (RU)

**Дорогая модель думает, дешёвые воркеры печатают.** Плагин для Claude Code (и Codex): ваша
интерактивная сессия становится лидом — планирует, пишет спецификации, проверяет код и живой
UI. Воркеры — headless-процессы Claude Code на моделях DeepSeek — пишут код, гоняют сборку,
тесты и ваши ревью-агенты, чинят по фидбеку. Полная документация — в [docs/](docs/)
(по-английски); это сжатая версия.

## Провайдеры

| | Эндпоинт | Серверы | Когда |
|---|---|---|---|
| `fireworks` (по умолчанию) | api.fireworks.ai | США | рабочие проекты |
| `hive` | api-cdn.thehive.ai | США | рабочие проекты (дешевле всего) |
| `deepseek` | api.deepseek.com | Китай | личные проекты |

Выбор: в проекте — `.claude/multiagents.json` → `{"provider": "hive"}`; глобально —
`multiagents provider hive`. С `deepseek` код и промпты уходят на китайские серверы —
выбирайте осознанно. Модель везде DeepSeek V4.1 Flash (зрение, контекст 1M); цены за 1M
токенов (вход / кэш / выход): Fireworks $0.22/$0.007/$0.66, Hive $0.12/$0.0024/$0.48 (цена со
скидкой), DeepSeek пик $0.30/$0.006/$1.20 (вне пика вдвое дешевле).

У Hive есть только OpenAI-совместимый API, а воркеры говорят на API Anthropic. Поэтому на время
каждого запуска CLI поднимает на 127.0.0.1 маленький мост-переводчик: ключ Hive остаётся внутри
моста, воркер получает лишь одноразовый токен к нему.

## Установка

```
/plugin marketplace add rudnytskyi1/multiagents
/plugin install multiagents@multiagents
```

Ключи (команда сама спросит ключ — в историю терминала он не попадёт):

```bash
security add-generic-password -s fireworks-api -a "$USER" -w
```

```bash
security add-generic-password -s deepseek-api -a "$USER" -w
```

```bash
security add-generic-password -s hive-api -a "$USER" -w
```

Проверка: `multiagents doctor` (или `/multiagents:setup` в чате).

Для Codex (репозиторий — ещё и Codex-плагин): `multiagents install-codex` — команда сама найдёт
`codex` (в PATH или внутри приложения ChatGPT/Codex), добавит маркетплейс и установит плагин;
повторный запуск обновляет плагин из того же источника.
Затем в новом треде Codex — `$multiagents:lead <задача>`. Команды воркеров Codex попросит
одобрить вне песочницы: им нужны сеть и Keychain. Подробно: [docs/codex.md](docs/codex.md).

## Как пользоваться

В git-репозитории, на именованной ветке (чистое дерево не требуется):

```
/multiagents:lead добавить экран настроек с тёмной темой
```

Цикл: план → спецификация задачи → кодер (ветка `ma/T00N-…`) → ревьюер (сборка, тесты, ваши
агенты из `.claude/agents/`) → лид сам смотрит дифф и запущенное приложение → либо merge
(`accept`), либо нумерованный фидбек со скриншотами фиксеру — максимум 3 круга. Лид сам код
не пишет (кроме мелочей и отладочных вставок — и говорит об этом). Все файлы задач лежат в
`.multiagents/` внутри репозитория и в git не попадают.

Каждая задача работает в собственном git worktree (отдельная папка-копия репозитория на своей
ветке), поэтому **независимые задачи идут параллельно**, а ваша основная папка вообще не
трогается — можно держать в ней несохранённые правки. Лид читает не полные отчёты, а «дайджест»
(`multiagents digest`) — вердикты и проблемные секции; полный дифф построчно он перечитывает
только там, где тесты не защищают (деньги, авторизация, миграции) или когда вердикт не PASS.

Говорите с лидом словами: «статус», «сколько потратили», «прими», «отклони», «вот замечания: …».

## Безопасность — коротко

Воркер — это `claude -p`, направленный на сторонний эндпоинт. Наивно так делать опасно: мы
наблюдали, как дочерний `claude -p` внутри приложения Claude отправлял OAuth-токен подписки
на подменённый `ANTHROPIC_BASE_URL`. Здесь четыре слоя защиты: полная очистка окружения
(включая все `*_API_KEY`), отдельный `CLAUDE_CONFIG_DIR` без вашего логина, self-test на
утечку перед первым запуском (канареечный ключ + локальный сервер-ловушка; FAIL блокирует
запуски), и недоверие к конфигу из репозитория (эндпоинты и источники ключей — только из
`~/.multiagents/config.json`). Честная граница: разрешённые интерпретаторы могут исполнять
произвольный код, поэтому воркер = «джун с шеллом на ветке», а настоящая защита — ваше ревью
перед `accept`. Подробно: [docs/security.md](docs/security.md).

## Если что-то не так

`multiagents doctor` покажет, что сломано; типовые случаи разобраны в
[docs/troubleshooting.md](docs/troubleshooting.md). Логи раунда — в
`.multiagents/tasks/T00N-…/NN-<role>.log`.
